**SATE BAKAR — Warung 60 Detik**: an original Indonesian night-warung satay-grill cooking game. One screen, full colour, warm charcoal glow. Take orders from the board, skewer chicken / beef / tofu / tempeh / mushroom, chop it, grill it on charcoal (heat fades — stoke it!), drizzle peanut / kecap / sambal sauce, garnish, plate and serve — in each recipe's own exact order. Wrong order fails the dish. Customers lose patience, combos multiply perfect serves, and the shift ends at 120 seconds: reach 1200 points to become a warung legend.

The fun, all real in code: consecutive PERFECT serves build a **PANAS!** flame streak that multiplies tips x2 → x4 (a burnt skewer, a wrong dish or a walkout kills it); once a shift the **JAM RAMAI** rush floods the warung — faster orders, faster-draining patience, double points; served customers answer back with **ENAK!** hearts while a walkout storms off with a **KABUR!**; and one **Pesanan Emas** golden order per shift — the shift's rare-ingredient bonus recipe (a different rare ingredient every shift, picked by the seed) — pays a +100 tip.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 — no build step, no network, plain static files. Play with mouse (click stations) and keyboard (WASD / arrows to move, E to use a station, Space to stoke the grill, R to restart, X to discard).
